# spoonacular
This text-based recipe app is dedicated to Indian cuisine, offering users a rich and diverse collection of recipes with easy access and customization. Leveraging the Edamam API, the application enhances culinary exploration by providing a wide variety of curated dishes, from traditional staples to modern twists. The app includes a seamless feedback system that allows users to share their thoughts without the need for mandatory sign-ups, promoting effortless engagement. All feedback and relevant data are securely stored using Supabase, ensuring real-time data handling, integrity, and scalability. Designed for simplicity and functionality, this application aims to elevate the cooking experience while gathering valuable user insights to continually improve and expand the recipe database.
